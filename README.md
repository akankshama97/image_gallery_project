# 🖼️ Image Gallery Project
A simple & interactive Image Gallery where users can browse and view images in a clean, beautiful layout with Lightbox view.

## 🔗 Live Demo
👉 https://imagegalleryproject-six.vercel.app/

## ✨ Features
- 📱 Fully Responsive Design - Mobile & Desktop dono par chalega
- ✨ Smooth Animations & Transitions
- 🔍 Image Lightbox View - Image ko badi screen par dekhne ke liye
- 🎨 Clean & Modern UI

## 🛠️ Tech Stack
- **HTML5** - Structure
- **CSS3** - Styling & Layout
- **JavaScript** - Interactivity & Image Handling
